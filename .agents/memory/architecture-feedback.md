# Architecture Feedback Memory

Use this file to prevent repeated AgentFlow review comments. Update it only with feedback that is
durable enough to affect future architecture proposals or implementation plans.

## Durable Feedback

- Add a short bullet when a user comment reveals a reusable rule, for example: "Invitation flows
  must create membership only after token acceptance."

## Resolved Decisions

- Record the final decision after a proposal version is approved.

## Avoid

- Do not copy every review comment here.
- Do not store raw customer data, invite tokens, credentials, or private personal information.
- Do not mark feedback resolved until the architecture or code actually changed.
