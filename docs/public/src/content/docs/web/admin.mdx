The admin package provides model registration, sites, staff access policies,
auth views, index pages, change lists, change forms, delete confirmation,
history, filters, search, autocomplete, widgets, inlines, actions, static
assets, and queue/admin docs integrations.

Generated projects mount `/admin/` automatically. Anonymous requests redirect
to `/admin/login/`; staff users created with `go run manage.go createsuperuser`
can sign in through the generated admin auth views. The generated admin uses
`.gogo/auth_users.json` for users and `.gogo/sessions` for admin sessions.

The admin index renders the registered model list from app `admin.go` metadata
so new apps are visible after `startapp` auto-installs their admin registration.
Model-level permissions are evaluated for the index, app list, change list,
forms, deletes, history, autocomplete, and actions.

## Model admin options

Admin registrations can configure list display, list filters, ordering, search,
readonly fields, fieldsets, forms, inlines, autocomplete fields, raw ID fields,
prepopulated fields, actions, custom URLs, computed columns, and lifecycle
hooks. Set `ReadOnly` for registrations that should expose staff-only list and
detail views while blocking add, change, and delete.

Change forms validate POST data through model metadata before persisting. A
site `ModelStore` that also implements `models.ObjectQueryStore` receives
search, filter, ordering, limit, offset, and total-count input for bounded
change-list queries. A site `LogStore` records additions, changes, deletions,
and actions for history pages.

Use `admin.CheckSite(site)` or `admin.RegisterChecks(registry, site)` to catch
invalid field names and conflicting admin options before release.

## Register metadata

```go
package blog

import (
	"github.com/cybersaksham/gogo/admin"
	"github.com/cybersaksham/gogo/models"
)

func RegisterAdmin(registry *admin.Registry) error {
	meta := models.Metadata{AppLabel: "blog", ModelName: "Post", TableName: "blog_post"}
	return registry.RegisterMetadata(meta, admin.ModelAdmin{
		ListDisplay: []string{"title"},
		SearchFields: []string{"title"},
	})
}
```

Admin access should stay behind active staff and permission checks. Keep
destructive actions auditable and require explicit permissions where needed.
